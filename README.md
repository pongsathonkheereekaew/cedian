# cedian

Cedia's native agentic tools: a personal agent workspace, owned end to end, in Rust.

A background daemon owns every agent session, terminal, browser and worktree, so work keeps running after the window closes. A native GPUI window draws them as panes: agent, terminal, file and editor, diff review, browser, with images and video shown inline.

The design decisions are in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md). The earlier version of cedian (a Zed fork driven by the OMP agent) is kept whole in the git history: the last commit before this change is `f442670` (tag `archive/omp-ide-2026-10-21`).
